# kadai-store

A responsive e-commerce demo built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Features
- Product listing, live search suggestions, category chips, filters (price, rating, brand, stock) and sorting
- Product detail view, shopping cart drawer with coupons, wishlist
- User authentication (sign up and sign in, stored in the browser)
- Checkout with address, delivery and payment (UPI, card, COD) validation, then order history
- Admin dashboard: KPIs, revenue chart, product management, order status updates, customers
- Light theme with six colour themes, minimal cursor interaction, mobile friendly

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).

## Demo logins
- Admin: `admin@kadai.in` / `admin123`
- Shopper: `demo@kadai.in` / `demo123`

All data lives in the browser's localStorage. Payments are simulated.
